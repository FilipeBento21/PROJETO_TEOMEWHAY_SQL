📘 Curso de SQL com SQLite – Estudo Prático com o TEO

👋 Olá!

Este repositório contém meus estudos práticos em SQLite, realizados através das aulas gratuitas no canal do YouTube TEO MY WHAY.
Ao longo dos episódios, pude ver minha evolução no uso do SQL, tema essencial no mercado de análise e ciência de dados.

🎯 Objetivo
Registrar meu progresso, reforçar meu aprendizado com prática constante e compartilhar com quem também estiver começando ou procurando materiais objetivos sobre SQL.

📚 Organização por Episódios
Os arquivos estão organizados por episódios (ep01, ep02, etc.), seguindo a sequência das aulas do canal. Cada pasta contém scripts .sql com as consultas feitas em aula e exercícios complementares.

🔍 Temas abordados:

🟢 Fundamentos (Ep01 - Ep02)
SELECT, WHERE, ORDER BY, GROUP BY, HAVING

Funções agregadoras: MAX(), MIN(), SUM(), AVG(), COUNT()

Filtros e operadores lógicos

🟡 Subconsultas e Condicionais (Ep03 - Ep04)
SUBQUERY (subconsultas internas)

CASE WHEN, COALESCE, ISNULL, DISTINCT

Condições em colunas derivadas

JOIN entre tabelas, incluindo INNER JOIN, LEFT JOIN

🔵 Análises e Estrutura de Dados (em Ep05+)
Análises mais complexas com junções e filtros avançados

Aplicações práticas para entender relacionamento entre tabelas
